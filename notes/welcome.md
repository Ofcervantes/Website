# Welcome to my notes

This is a sample markdown note. Anything you drop into the `/notes` folder
shows up automatically in the **Notes** section of the site.

## How it works
1. Add a `.pdf` or `.md` file to `/notes`
2. `git push`
3. A GitHub Action regenerates the list and redeploys the site

## Markdown is fully supported
- Lists
- **Bold** and *italic*
- `inline code`
- Links, tables, blockquotes, code blocks
