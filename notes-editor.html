Local notes admin

Create and save a Markdown note.

This private tool runs on your computer and writes directly to the notes/ folder. It is excluded from the published website.

Write your note

Enter a title and your Markdown, then save the finished file through the local backend.

Filename: untitled-note.md

The preview shows the exact file as safe text. Raw HTML is never executed.

Keyboard shortcut: Ctrl/⌘ + S saves the note.

After saving

Review and publish through GitHub.

  1. The backend writes the Markdown file to notes/ and refreshes the local manifest.
  2. Review the note on your local Notes page.
  3. Commit and push when you are ready; GitHub Pages publishes the updated archive.
